# Nimbus — New Tab

Nimbus is a personal browser homepage designed to replace the default new tab page. It works offline and can be installed as an app. Everything stays local — no accounts, no tracking, no cloud sync.

## What's on the page

- **Clock** — Current time and date at a glance
- **Search Bar** — Search the web without navigating away
- **Weather** — Live conditions based on your location
- **Panchang** — Hindu calendar details for today
- **Bookmarks** — Your most-used links, one click away
- **Sticky Notes** — Floating notes you can drag, rotate, style, and write in markdown
- **Tasks** — A simple to-do list with markdown and checkbox support
- **Theme** — Light, dark, or system theme
